# Documentation Guide

Use these documents as lightweight review aids before adding an MCP server, enabling an agent tool, publishing an extension, or preparing a public demo.

| Document | Use when |
|---|---|
| [MCP readiness](mcp-readiness-checklist.md) | Reviewing server configuration, ownership, scopes, and release evidence |
| [Tool exposure review](agent-tool-exposure-review.md) | Deciding which agent tools are necessary and how they should be bounded |
| [Secret-risk checklist](secret-risk-checklist.md) | Preparing a public repository, demo, screenshot, or listing |
| [IDE setup guide](ide-mcp-setup-guide.md) | Validating a client configuration without using production credentials |
| [Extension readiness](extension-launch-readiness.md) | Preparing a browser extension or marketplace submission |
| [Browser-terminal safety](browser-terminal-safety-checklist.md) | Designing a workflow that can affect browser, terminal, files, or local services |
| [Public-safe demo](public-safe-demo.md) | Rehearsing a synthetic demo |
| [Partner pitch](partner-pitch.md) | Introducing the pack to a partner or directory |
| [Pricing strategy](pricing-strategy.md) | Discussing packaging without enabling payments |

Record only sanitized findings. A completed checklist is evidence of a review step, not a security guarantee.
