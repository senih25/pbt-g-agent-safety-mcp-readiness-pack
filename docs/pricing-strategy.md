# Pricing Strategy

## Principle

Use marketplace listings for discovery and trust. Do not depend on a single Stripe-only payout channel. Keep the first public asset free or freemium, then route qualified users into a direct pilot, sponsorship, or partner model.

## Package tiers

### Free discovery package

- Public checklists
- Synthetic demo workflow
- IDE/MCP setup validation guide
- Marketplace readiness notes
- Public-safe boundaries

Goal: distribution, inbound leads, GitHub stars, directory visibility, and partner credibility.

### Solo developer pack

Indicative price: USD 20/month where legally and operationally supported.

Includes:

- guided review templates
- setup validation workflow
- launch-readiness review checklist
- periodic update notes

### Startup/team pack

Indicative price: USD 99/month where supported.

Includes:

- team-oriented MCP exposure review
- release checklist support
- partner/listing copy review
- one monthly async review slot

### Platform / enterprise pilot

Custom price. Start with a limited-scope technical pilot, then convert into licensing, revenue share, or integration partnership.

## Payment constraints

Stripe may not be usable for a Turkiye-based seller. Use non-Stripe-dependent options where suitable:

- Whop, if seller onboarding is available
- GitHub Sponsors
- direct invoice / bank transfer
- partner-handled Merchant of Record
- Lemon Squeezy or similar MoR only after legal/availability verification
- free marketplace listings as lead generation

## No-go

Do not create paid accounts, enable billing, connect payout providers, or publish payment terms without human approval.
