# Partner Pitch

## One-line positioning

PBT-G Agent Safety & MCP Readiness Pack helps teams review MCP configuration hygiene, agent tool exposure, and browser/terminal workflow risk before they publish, demo, or scale agent integrations.

## Problem

Agent platforms increasingly expose browser, terminal, file, local workflow, and remote MCP capabilities. These capabilities create useful automation paths, but they also create context bloat, unclear tool boundaries, secret-handling risk, and uncertain approval gates.

## Public-safe offer

This pack provides a non-invasive, synthetic-data-only readiness layer:

- MCP server setup review
- agent tool exposure checklist
- browser/terminal workflow review
- public repository secret-risk checklist
- IDE/client setup validation notes
- marketplace and extension launch-readiness guidance
- partner-safe demo script

## What is not included

The pack does not include PBT-G core source code, guard internals, policy engine details, private repos, secrets, customer data, or implementation mechanisms. It is guidance and review material, not a security certification.

## Partner options

1. Directory listing: publish the pack as a free MCP/agent safety resource.
2. Platform pilot: test the review workflow against a synthetic agent integration.
3. Connector package: adapt the checklist and setup guide to the partner ecosystem.
4. Commercial path: licensing, revenue share, or platform safety partnership after validation.

## Call to action

Request a 20-30 minute technical fit call and offer a public-safe demo.
