# Chrome Extension and Marketplace Launch-Readiness Checklist

## Product clarity

- [ ] The listing states what the extension does, who it serves, and its limits.
- [ ] Screenshots use a synthetic account and contain no secrets, customer data, or private tabs.
- [ ] Claims are supported and do not imply certification, complete protection, or platform endorsement.

## Permissions and data

- [ ] Each requested permission has a user-facing explanation and a documented necessity.
- [ ] Host permissions are as narrow as the supported use case allows.
- [ ] The privacy notice explains data behavior in plain language.
- [ ] No embedded secrets, test credentials, private endpoints, or debug logs are included.

## Release operations

- [ ] Version, changelog, support route, security contact, and rollback owner are prepared.
- [ ] The package was tested in a clean browser profile with synthetic data.
- [ ] Store policies and required disclosures were checked on the day of submission.
- [ ] Submission, publishing, billing, or account changes await owner approval.

## Marketplace-safe narrative

Describe the extension as a workflow aid and explain the user’s control points. Do not describe or demonstrate bypassing platform safeguards or extracting data from accounts.
