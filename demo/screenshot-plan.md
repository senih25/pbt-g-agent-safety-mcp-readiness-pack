# Screenshot Plan

## Capture only

- README title and purpose section
- checklist headings
- synthetic config excerpt
- demo flow diagram if created later
- marketplace draft with no private contact or unpublished claims

## Do not capture

- private repo names unless already intended for public context
- local Windows account paths
- terminal history with commands that include secrets or paths
- browser cookies, account menus, emails, tokens, API keys
- investor dashboard or intake internals

## Recommended screenshots

1. Public package README overview
2. MCP readiness checklist section
3. Synthetic config file
4. Marketplace listing draft security boundary
5. Approval-gate table from final report
