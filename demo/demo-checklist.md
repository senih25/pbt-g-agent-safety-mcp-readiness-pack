# Demo Checklist

- [ ] Use only synthetic files.
- [ ] Use a clean browser profile or safe local docs view.
- [ ] Hide local username and private paths from screenshots.
- [ ] Do not show `.env`, `.key`, `.pem`, `.pfx`, `.dpapi`, cookies, tokens, or browser credential stores.
- [ ] Do not open private core source.
- [ ] Do not claim certification, compliance, or guaranteed safety.
- [ ] Use dated claims only when evidence is available.
- [ ] Record findings by class, not by secret value.
- [ ] Stop before any publication or external submission.
