## Canonical long description

PBT-G Agent Safety & MCP Readiness Pack is a public-safe resource for developers, maintainers, and platform teams preparing MCP servers, AI agent tools, browser automation, terminal workflows, or marketplace listings. It provides structured checklists, setup validation guidance, and synthetic demo material without requiring private repositories, secrets, customer data, or core PBT-G implementation details.

This pack helps teams review:

- MCP configuration hygiene
- agent tool exposure
- browser and terminal workflow boundaries
- public repository secret-risk patterns
- IDE/client setup readiness
- extension and marketplace launch readiness
- partner-safe demo preparation

It is not a security certification, penetration test, compliance opinion, or managed monitoring service.
